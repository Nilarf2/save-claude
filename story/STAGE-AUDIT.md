# 舞台计划与检查

`story/stage-plan.json` 保存正式舞台意图，编译器将其展开为 `web/story.json` 的场景与逐行快照。当前剧情为 69 章、18 个结局；行数和节点数应从当次编译取得，不使用历史审查数字。

## 数据约定

- `line.stage` 是显示本行前要达到的完整目标，`scene.stage` 只作初始值。
- 快照明确 `present`、`slots`、`focus`、`expressions`、`enter`、`exit`、`background` 与 `continuity`。
- 最多同时两名角色；发言改变 focus，不交换左右。跨同一连续场景保留站位，真实退场及时清槽。
- 照片、录音、档案、名字提及和画外声音不自动加入舞台；多方会谈可通过切镜换搭档。
- Codex 与 GPT 使用同一个 canonical ID `gpt`，不创建第二名角色。

## 维护与验收

运行 `npm run build` 后执行 `npm run check:stage`。该检查核对所有行的快照字段、角色与资源引用，以及关键出入镜、动作和背景切换；它不等于逐行人工作图验收。

舞台变化还需用真实浏览器定向看受影响行，至少核对说话者明暗、左右稳定、退场、背景/立绘先于首字，以及读档和横竖屏。图像本身的构图瑕疵应在素材中修正，不能以舞台裁切或遮挡代替。
