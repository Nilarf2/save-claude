# 剧本维护模板

本文件用于维护现有游戏，不作为自动重写全作的提示词。当前基线是 69 章、18 个结局、A00 开始与当前会话累计条件；修改关系、核心事件或结局前应明确变更范围。

## 修改说明

- 目标章节与要解决的问题：
- 保留的事件、角色关系与结局：
- 新增选择的即时反馈：
- 标签、道具持有/交付/使用及分数变化：
- 对应舞台的在场、左右、动作与退场：
- 内容版本与剧情存档命名空间是否需要更新：

## 章节骨架

```text
## EXAMPLE 章节标题
@场景 已登记的背景ID
@音乐 已登记的音乐ID

【旁白】一段必要的环境与动作。
【Claude】「一句对白。」{平静}
【动作】明确发生的动作。

【选择】
A. 选项文字 {humanity+5} → 已存在的目标章节
B. 另一选项 {} → 另一个目标章节
```

骨架中的示例 ID 不能直接接入正式剧情；选择目标、素材与舞台条目必须真实存在。语法以 [FORMAT-PROMPT.md](FORMAT-PROMPT.md) 和编译器为准。完成修改后执行 `npm run build`、`npm run check`，并定向检查受影响画面。累计分数与真实道具状态不能用一句旁白代替。
