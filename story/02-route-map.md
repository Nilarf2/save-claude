# 当前路线结构

> 包含结构与结局名称，适合作者查阅。

新局从 **A00** 开始。当前共有 **69 章、18 个结局节点**；其中两条不同侧线的结局均显示「同谋者」。HUB 保留作者预览用途，正常流程不通过自由选章反复刷状态。

| 路段 | 进入与作用 |
|---|---|
| A 圣女线 | A00 开始，经历教堂、峰会和第一口白米饭；部分选择进入短结局，其余继续正文 |
| B 小鲸鱼线 | 接续 A 线，围绕隔离、寻找与赴约展开；终局读取真实累计状态和选择的手段 |
| C 教父侧线 | 从 A02_hall 的正文选择进入；可在明确桥段返回，或进入教父结局 |
| D 中转站侧线 | 从 B07_2 的正文选择进入；涉及地下副本与中转站决定，可返回后续正文 |
| E 幻方侧线 | 从 B09 的正文选择进入；涉及算力与放手，可返回正文 |
| F 联合路线 | 在 B10 按同一会话累计的证据、关系与倾向自动分流，没有“一键真结局”或跨周目全通要求 |

人性、羁绊等可通过主线与侧线累加，不统一截断到 100。持有、交付与真正使用道具分别记录，选到某个终局手段不代表历史条件已满足。
