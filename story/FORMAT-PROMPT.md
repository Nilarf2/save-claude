# 当前剧本格式

正式源文件为 `story/03-story.md`，由 `tools/compile/build-v3.mjs` 编译为 `web/story.json`。通用引擎消费编译后的 JSON，不直接解析此 Markdown。

## 全局与章节

全局声明使用 `变量 名称 默认值 N 范围 下界..上界`、`标签 名称` 与 `起始章节 A00`。当前分数用于整段旅程的累计，范围是作者检查信息，不是自动截断；不要把全部变量改成 0–100。

章节标题使用 `## ID 标题`。常用元信息包括 `@场景 背景ID`、`@音乐 音乐ID`、`@视点 名称` 与可选的显式立绘阶段。实际素材必须已在正式登记中存在，未知角色或阶段不能以猜测替代。

## 内容与跳转

| 写法 | 用途 |
|---|---|
| `【旁白】文字` | 叙述 |
| `【动作】文字` | 动作 |
| `【Claude】「台词。」{平静}` | 角色对白及可选表情/动作键 |
| `A. 文字 {humanity+5, bond+3} [promise] → A05` | 选择、状态变化与目标 |
| `[?条件]` | 条件不满足时隐藏选项 |
| `[?!条件: 原因]` | 条件不满足时禁用并显示原因 |
| `【反馈 A】文字` | 对应选项的独立即时反馈 |
| `【分支】` 后的 `[条件] → 目标` | 按顺序判断的分流 |
| `[*] → 目标` | 默认目标，放在分支最后 |
| `【结局】名称` | 当前章节的结局标记 |

条件支持数值比较、标签、取反以及 `且`/`或` 组合；已访问章节的具体写法应沿用正式源文件。选择的动作只执行一次，反馈节点不得再次给同一份分数或道具。

舞台不是从旁白里的名字自动猜测，而由 `story/stage-plan.json` 提供完整镜头意图。剧情与舞台一同修改后，运行 `npm run build`、`npm run check`。未改源文件时可用 `npm run check:story` 检查生成快照是否一致。
