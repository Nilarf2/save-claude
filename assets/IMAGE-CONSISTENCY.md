# 图像一致性检查

本文件说明当前制作目标，不把某个生成模型、批次或遮罩方法的历史效果当作保证。

1. 先核实角色身份、参考来源与允许使用范围；剧情服饰和道具以当前正式约定为准。
2. 同一角色同一服装保持头发、头纱、胸饰、袖型与道具结构；表情变化不应变成另一套人设。
3. 构图完整保留发顶、外侧发丝、手与道具，检查原图边缘是否已有硬切口；透明留白不能补回被截断的内容。
4. 检查 alpha、棋盘底、杂边及暗底可读性；不要用模糊或遮挡假装修复。
5. 将默认图与必要表情/动作并排目视，再在真实游戏对应行检查左右位置、焦点、退场和横竖屏。
6. 仅把已审阅的实际文件登记到运行时清单；未有新表情时按同角色默认图回退，不混回另一套服装。

当前正式立绘位于 `web/assets/char-redrawn/`，提示词位于 `assets/char-redrawn/prompts/`。AI 生成记录证明制作过程，不构成对参考图或角色的第三方授权，见 [素材授权说明](../ASSET-LICENSE.md)。
