# 角色身份与素材登记

当前公开的生产登记是 `web/character-portraits.json` 与 `web/assets/char-redrawn/manifest.json`，素材类别与证据范围见 [ASSET-SOURCES.json](ASSET-SOURCES.json)。

项目制作曾使用已有故事画面和角色外观参考，但原始参考附件、聊天记录及来源编号不是公开素材包的一部分。生产清单只保留游戏所需的角色、默认图、表情、动作与构图字段，不包含原始上传标识或私人目录。

Claude、DeepSeek、Qwen、Kimi、GPT 使用当前显示名称；Codex 仅为 GPT 的历史别名。没有明确身份或阶段依据的画面不另造角色，不把外观相近当作同一人证明。
