# 立绘制作方向

角色外观约定见 [ART-BIBLE.md](ART-BIBLE.md)。正式剧本决定服装语境、动作与道具；没有核实的参考不能推断成角色身份或另一年龄阶段。

- Claude 保留长蕾丝头纱、橙花黑缎带与米白/黑金结构；茶杯与瓷碟是实际剧情道具，不将其改称咖啡。
- 修女保留压低的黑兜帽与银色卡尺，不因默认立绘方便而移除必要道具。
- DeepSeek 的鲸鱼服与饭盆、Qwen 的折扇、Kimi 的书记官道具按正在发生的动作呈现；录音出现不代表本人入镜。
- 对话素材以透明半身为主，画面留出发丝、头纱与配饰外缘；不要把贴原图边缘的硬切口交给 CSS 隐藏。
- 同一服装先确定默认形象，再派生必要表情/动作；不镜像有方向性的饰物或道具。

正式素材由 `web/character-portraits.json` 登记。替换图像后应目视核对透明背景、头肩位置、手和道具、暗化可读性、手机与横屏；完成情况由本次审阅决定，不沿用历史批次的“全部修复”结论。
