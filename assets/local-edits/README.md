# 局部美术修订

此目录记录当前版的领口与屏幕插图修订。原始整图生成、表情和补边提示词继续保留在各自目录；重做当前版时，还须应用这里的局部要求，不能直接把旧提示词当成最终服装规格。

GPT 使用不透明米白内襟，Grok 使用黑色内搭；哈基米仅补齐胸前开口，保留短上衣下摆及露腰。封面同步处理哈基米胸前衣料，保留标题、六位角色的脸和原构图。四处背景屏幕或白板使用虚构网络节点、波形和计算拓扑，不作现实地图使用。

`manifest.json` 列出基线提交、提示词、原尺寸合成区域和裁剪映射。区域图中白色允许替换、黑色保留原图；提交给图片编辑接口的 PNG alpha 遮罩语义相反：不透明保护，透明允许编辑。生成用的局部放大或上下补画布仅用于编辑，不改变正式素材的画幅。

先备份基线图，在允许区域内生成候选，再把合格的衣料或屏幕内容局部合成回原画布。保留立绘原透明通道；边缘柔化应限制在审核过的区域内。局部生成可能重复饰品或没有真正遮挡，必须检查实际图像，不能仅凭请求成功或文件变化验收。未选候选、服务请求日志和凭据不属于公开素材。

检查胸前接缝、饰品、脸、头发和道具；在深浅背景、棋盘格及实际游戏的手机和桌面显示中复核。营销 JPEG 会有正常的再编码微差；修改后的立绘与主封面使用无损 WebP，四张背景以质量 95 编码 WebP 控制包体；16:9／4:3 营销 JPEG 分别使用质量 95／92。素材权利说明见根目录 `ASSET-LICENSE.md` 和 `SOURCE-NOTICE.md`。
