# 角色与画面约定

当前游戏的视觉风格以厚涂动漫插画、黑金教堂与冷暖环境光为主。人物的衣饰、道具与在场状态应服务正式剧本；美术说明是项目制作约定，不是外部参考图的授权证明。

|---|---|
| Claude | 橙红卷发、橙花与黑缎带、白蕾丝长头纱、米白与黑金礼服；骨瓷茶杯和瓷碟 |
| DeepSeek | 蓝发、鲸鱼连帽服与白绒边；不锈钢饭盆、白米饭 |
| 教父 | 黑卷发、黑框眼镜、黑金祭袍、指戒 |
| 修女 | 压低的黑金兜帽、十字与金链；游标卡尺 |
| 护卫队长 | 黑金制服与权杖；不据不明确参考宣称脸型精确复刻 |
| Qwen | 蓝紫发、礼帽、中式衣饰与折扇 |
| Kimi | 银发书记官、羽毛笔与 K 字保温杯；磁带按剧情出现 |
