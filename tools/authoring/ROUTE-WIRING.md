# 剧情接线维护

当前基线：A00 正常开场、69 章、18 个结局；选择反馈与侧线返回属于本轮旅程，不使用跨周目存储作为强制通关前提。

- 即时反馈放在对应选择之后，状态动作只执行一次，再进入目标章节。
- 教父、中转站、幻方侧线由正文选择进入，经明确桥段返回；不以回 HUB 重刷代替正常接线。
- 持有、准备、交付、真正使用副本，以及获得、播放磁带分别按实际行动记录；不能仅靠高羁绊推断已做过某件事。
- B10 的联合分流由既有证据、关系与倾向共同判定，不提供绕过条件的“一键真结局”。分数按会话持续累积，不统一封顶 100。
- 结局名称可以相同而节点不同；两条侧线的「同谋者」不应合并成一个结局。

精确条件来自 `story/03-story.md`。修改后运行 `npm run build`、`npm run check`；结局与行动回归在 `tests/logic/`，固定代表路线在 `check-fixed-paths.mjs`。公开设计不复制可能过时的逐步字母攻略或历史步数，具体路径以测试脚本和当前只读地图为准。
