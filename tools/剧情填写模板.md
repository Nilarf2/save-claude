# 文字冒险内容填写模板

把方括号中的提示替换成你的内容。不适用的栏目可留空。剧情请按发生顺序编号；需要分支时，给每个场景、选项和结局起一个不重复的名称。收到填写版后，我会整理为引擎可运行的数据并制作示范。

- 故事发生的时代/地点：
- 世界观与重要规则：
- 玩家扮演谁：
- 故事开场时的处境：
- 希望玩家感受到什么：
- 预计篇幅：

## 2. 角色

每名角色复制一份。

### 角色

- 角色名：

- 角色秘密或剧情作用：
- 可选表情（如平静、开心、生气）：

## 3. 场景

每个场景复制一份，并给场景起唯一名称。

### 场景

- 场景名：
- 场景描述：
- 背景图需求或文件名：
- 背景音乐需求或文件名：
- 环境音/音效需求：
- 进入场景时发生什么：
- 场景结束后进入哪个场景或剧情节点：

## 4. 剧情与台词

每一段剧情写清顺序。旁白和角色台词分开；需要停顿或强调时写在备注中。

### 剧情段落

- 所属场景：
- 段落名称：
- 发生顺序：
- 旁白文本：
- 角色名：
- 台词：
- 表情/语气：
- 说完后发生什么：继续、进入选项、切换场景、触发事件或结束

## 5. 玩家选项

每组选项复制一份。若选择有前置条件，请写明；没有条件就填“无”。

### 选项组

- 选择 A 后进入的场景/剧情段落：
- 选项 B 文本：
- 选择 B 需要的条件：
- 选择 B 后的状态变化：
- 选择 B 后进入的场景/剧情段落：
- 其他选项：
- 玩家不满足任何选项条件时怎么办：
